# Banking Laboratory

## Overview

This project implements a secure banking system using Python object-oriented programming principles.

Features include:

- Customer management
- Checking and savings accounts
- Deposits
- Withdrawals
- Transfers
- Currency conversion
- Custom exception handling
- Logging
- Pytest unit testing
- Ruff code quality validation
- GitHub Actions continuous integration
